# История и культура народов КБР · Электронный учебный архив

Интерактивный академический веб-архив учебных материалов, конспектов и фотосхем лекционной доски по курсу истории Кабардино-Балкарии.

## 📖 Содержание архива

1. **Тема 01. Бронзовый век на Центральном и Северо-Западном Кавказе**
   - Майкопская культура, дольмены, Северокавказская культура, археологическая периодизация.
   - 2 фотосхемы конспектов с доски.
2. **Тема 02. Происхождение балкарцев и карачаевцев**
   - Кавказский субстрат, аланское наследие, тюркский компонент, данные археологии и антропологии.
   - 1 фотосхема конспекта с доски.
3. **Тема 03. Кабарда и Балкария в системе кавказской политики России (XVI — первая треть XIX века)**
   - Дипломатические связи (посольство 1557 г.), сословная структура Кабарды, традиционные балкарские общества.
   - 3 фотосхемы конспектов с доски.

## 🚀 Как запустить и опубликовать на GitHub

### Вариант 1. Публикация через GitHub Pages (доступ с любого браузера и телефона)

1. Создайте новый репозиторий на [GitHub.com](https://github.com/new) (например, `kbr-history`).
2. В терминале папки проекта выполните:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Electronic archive of KBR history"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/kbr-history.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в:
   **Settings** → **Pages** → в разделе **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)`
   - Нажмите **Save**.
4. Через 1-2 минуты сайт станет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/kbr-history/`
   *(эту ссылку можно открывать с любого телефона, планшета или компьютера).*

### Вариант 2. Быстрый просмотр с телефона по локальной сети Wi-Fi

Если ваш компьютер и телефон подключены к одному Wi-Fi, запустите в папке проекта:
```bash
python3 -m http.server 8000
```
Затем посмотрите локальный IP-адрес Mac (например, `192.168.1.50`) и откройте на телефоне в браузере:
`http://192.168.1.50:8000`
